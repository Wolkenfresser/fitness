# 📋 Устав проекта — FitPulse

## 1. Идентификация проекта

| Поле | Значение |
|---|---|
| Название | FitPulse |
| Тип | Мобильное приложение |
| Платформа | iOS / Android (React Native + Expo) |
| Версия | 1.0.0 |
| Статус | ✅ Реализован |

## 2. Цель проекта

Разработать красивое мобильное фитнес-приложение с поддержкой тёмной темы, которое позволяет пользователю выбирать тренировки, запускать живой таймер, отслеживать прогресс и управлять профилем.

## 3. Заинтересованные стороны

| Роль | Описание |
|---|---|
| Разработчик | Студент-исполнитель |
| Преподаватель | Принимает и оценивает работу |
| Конечный пользователь | Человек, занимающийся фитнесом |

## 4. Границы проекта

**В рамках проекта:**
- Каталог тренировок с фильтрацией
- Живой таймер с управлением сессией
- Экран статистики с графиками
- Профиль пользователя с ИМТ

**Вне рамок проекта:**
- Синхронизация с сервером
- Аутентификация
- Push-уведомления
- Интеграция с носимыми устройствами

## 5. Критерии успеха

- [ ] Приложение запускается на Android/iOS через Expo Go
- [ ] Навигация между 4 экранами работает корректно
- [ ] Таймер отсчитывает время и поддерживает паузу
- [ ] Кольца прогресса анимируются при загрузке
- [ ] Фильтрация тренировок работает в реальном времени

## 6. Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Несовместимость версий Expo | Средняя | Зафиксированы версии в package.json |
| Отсутствие Android Studio | Высокая | Используем Expo Go без сборки |
| Медленный npm install | Низкая | Кэш npm |
