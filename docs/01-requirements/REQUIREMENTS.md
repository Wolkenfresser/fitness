# 📝 Требования к системе — FitPulse

## Функциональные требования

### FR-01: Главный экран (Dashboard)
- Система **должна** отображать имя пользователя и приветствие
- Система **должна** показывать серию активности (streak) с иконкой огня
- Система **должна** отображать недельный календарь с отметками выполненных тренировок
- Система **должна** показывать 3 кольца прогресса: тренировки, калории, серия
- Система **должна** отображать краткую статистику (всего тренировок, часов, калорий)
- Система **должна** показывать список рекомендованных тренировок

### FR-02: Каталог тренировок
- Система **должна** отображать список всех тренировок в виде карточек
- Система **должна** поддерживать фильтрацию по категории (Кардио, Сила, HIIT, Растяжка)
- Система **должна** поддерживать фильтрацию по уровню (Лёгкий, Средний, Тяжёлый)
- Система **должна** показывать количество отфильтрованных тренировок
- Каждая карточка **должна** отображать: иконку, название, категорию, длительность, калории, кол-во упражнений

### FR-03: Детали тренировки и таймер
- Система **должна** отображать полную информацию о тренировке
- Система **должна** запускать таймер по нажатию кнопки «Начать»
- Таймер **должен** поддерживать паузу и возобновление
- Система **должна** отображать текущее упражнение, подходы и повторения
- Система **должна** позволять переходить к следующему упражнению
- Кнопка последнего упражнения **должна** завершать тренировку
- После завершения система **должна** показывать экран поздравления с итоговым временем

### FR-04: Прогресс
- Система **должна** отображать сводку за текущую неделю (дни, калории, минуты)
- Система **должна** показывать гистограмму калорий по дням недели
- Система **должна** показывать гистограмму минут тренировок по дням
- Система **должна** выделять день с максимальной активностью
- Система **должна** отображать статистику за всё время (тренировки, калории, часы, рекорд серии)
- Система **должна** показывать баннер текущей серии с рекордом

### FR-05: Профиль
- Система **должна** отображать аватар, имя, цель пользователя
- Система **должна** показывать показатели тела: вес, рост, возраст
- Система **должна** рассчитывать и отображать ИМТ с классификацией
- Система **должна** отображать достижения (разблокированные и заблокированные)
- Система **должна** содержать переключатели настроек (уведомления, звук, тема)
- Система **должна** позволять выбирать уровень подготовки

## Нефункциональные требования

### NFR-01: Производительность
- Запуск приложения: не более 3 секунд на Expo Go
- Анимации: 60 fps на устройствах с Android 8+

### NFR-02: Дизайн
- Тёмная тема как единственная (dark-first)
- Акцентный цвет: #C8FF00 (неоново-зелёный)
- Минимальный размер тапа: 44×44 pt

### NFR-03: Совместимость
- Android 8.0+ (API 26+)
- iOS 13+
- Expo SDK 51

### NFR-04: Структура кода
- Компоненты в `src/components/`
- Экраны в `src/screens/`
- Данные в `src/data/`
- Тема в `src/theme.js`
