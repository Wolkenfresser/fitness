  - Профиль с ИМТ

## Известные ограничения MVP

1. Данные не сохраняются между сессиями (нет SQLite/AsyncStorage)
2. Нет реальной аутентификации
3. Статистика не обновляется реальными тренировками
4. Нет сетевых запросов (полностью offline)
